# TaskFlow

TaskFlow is a clean and responsive project management web application designed to help users organize projects, manage tasks, track priorities, and monitor progress.

## Features

- Create and manage tasks
- Create and organize projects
- Task status tracking
- Priority management
- Project-specific task filtering
- Search tasks
- Progress tracking
- Task completion statistics
- Due dates
- LocalStorage data persistence
- Responsive interface

## Technologies

- HTML5
- CSS3
- JavaScript
- LocalStorage

## Getting Started

1. Clone the repository.
2. Open the project folder.
3. Open `index.html` in a browser or use VS Code Live Server.

## Data Storage

TaskFlow uses browser LocalStorage to save tasks and projects locally. No external database is required.

## Project Purpose

This project was built as a practical frontend web application to demonstrate UI design, JavaScript functionality, state management, filtering, and browser-based data persistence.
